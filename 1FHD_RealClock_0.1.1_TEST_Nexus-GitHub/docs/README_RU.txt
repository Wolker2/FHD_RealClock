FHD Real Clock 0.1.1 TEST
Космические Рейнджеры HD: Революция / Space Rangers HD: A War Apart

Установка

1. Закройте игру.
2. Распакуйте архив в папку с Rangers.exe. Папка Mods должна
   объединиться с одноимённой папкой игры.
3. Запустите игру, включите FHD_RealClock в разделе FHD_MODS
   и полностью перезапустите игру.
4. Начните новую игру или загрузите сохранение. Часы появятся
   у верхнего края игрового кадра, строго по центру.

Отключение

Выключите FHD_RealClock в меню модов и полностью перезапустите игру.
Для удаления можно убрать Mods\FHD_MODS\FHD_RealClock после закрытия игры.

Как это работает

Часы показывают местное время Windows в 24-часовом формате ЧЧ:ММ.
Отступ от верхнего края кадра составляет 3 пикселя. Панель
масштабируется по высоте игрового кадра и сохраняет его горизонтальный центр.

Штатный загрузчик ScriptLibs подключает DLL при начале и загрузке игры.
DLL распознаёт две поддерживаемые версии по трём точным сигнатурам
вызова EndScene, проверяет все сигнатуры перед установкой и рисует
панель непосредственно перед выводом финального кадра.
В планетарных боях MatrixGame часы не выводятся.

Статус проверки

Тестовая сборка. Обе версии EXE проверены на уровне машинных
инструкций с тестовым устройством D3D9. Проверены 3 пути отрисовки,
перенос образа в памяти, разрешения от 1280×960 до 3840×2160,
отсутствие секунд, смена минуты, переход через полночь, восстановление состояния рендера, отказ
на чужих байтах и откат частичной установки.
Main.dat совпадает побайтно с проверенным файлом из версии 0.1.0.
Игровой запуск требуется проверить на Windows.
