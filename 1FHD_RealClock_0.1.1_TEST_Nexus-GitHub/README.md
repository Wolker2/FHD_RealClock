## Сборка и ограничения

В оригинальном `SOURCE/BUILD.md` описаны MinGW-w64 x86, Python, `rangers-utils` и тесты проверки PE. Готовая DLL и `CFG/Main.dat` находятся **внутри оригинального ZIP** — они не изменялись при публикации.

Это **тестовая** версия: часы без секунд (HH:MM), верхний отступ 3 пикселя, расположение по центру. Код использует сигнатуры для **двух конкретных версий Rangers.exe**, поэтому универсальная совместимость с EXE не заявляется.

Проверка публикации подтверждает только целостность исходников и оригинального ZIP; она **не** компилирует DLL и **не** запускает игру. Предыдущие версии не изменяются.
