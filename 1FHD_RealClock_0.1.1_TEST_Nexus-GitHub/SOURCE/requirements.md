# Требования FHD Real Clock

- Местное время Windows в формате HH:MM после старта новой игры и после загрузки сохранения.
- Центр по горизонтали и 3 пикселя сверху в системе координат игрового кадра. Масштаб панели от 1× до 2× по высоте кадра.
- Регистрация штатным механизмом Data.ScriptLibs и обработчики BV.OnStart и BV.OnLoad.
- Нативный вывод ограничен тремя вызовами завершения финального кадра. Версия распознаётся перед установкой всех трёх точек.
- Архив установки содержит ModuleInfo.txt, CFG/Main.dat, Native/FHDRealClock.dll, инструкцию и исходники.
