FHD RealClock v1.3 D3D9 TEST
Космические Рейнджеры HD: Революция

Установка

1. Закройте игру.
2. При переходе с версии 1.1 или более ранней замените папку
   Mods\FHD_MODS\FHD_RealClock целиком. При обновлении с 1.2 можно
   распаковать архив поверх. Для новой установки распакуйте архив
   в папку с Rangers.exe.
3. Включите FHD_RealClock в разделе FHD_MODS и перезапустите игру.
   Часы появляются после начала новой игры или загрузки сохранения.

Настройки

ЛКМ по часам открывает меню. Повторный клик по часам, кнопка X,
Esc или клик за пределами меню закрывают его. Дату и рамку можно
скрывать независимо. При скрытой дате время центрируется по высоте.
Ползунок задаёт прозрачность рамки от 0% до 100%. Цифры и дата
сохраняют читаемость при любом значении ползунка. Для двух строк
можно независимо выбрать цвет. Первый образец возвращает штатный цвет.

Настройки сохраняются в Native\FHDRealClock.ini рядом с DLL.
Значение ползунка записывается при отпускании ЛКМ.

Проверка

Проверены в эмуляции машинного кода Steam/GOG 13.10.2025 и предрелиз
06.10.2026. Тесты охватывают шесть разрешений, ввод мышью, ползунок,
палитры, чтение и запись настроек, восстановление состояния D3D9
и постановку областей панели на перерисовку в аппаратном режиме.
Запуск в самой игре требуется проверить на Windows.
Планетарные бои MatrixGame используют отдельную отрисовку.

Отключение

Выключите мод в меню и полностью перезапустите игру.
