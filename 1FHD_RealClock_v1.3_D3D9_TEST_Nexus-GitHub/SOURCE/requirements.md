# Требования FHD RealClock v1.3

- Местное время Windows ЧЧ:ММ и реальная дата с днём недели.
- Панель по центру кадра с отступом 3 пикселя сверху.
- Меню по ЛКМ, отдельные переключатели даты и рамки, прозрачность рамки от 0% до 100%.
- Независимые палитры цифр и даты, сохранение параметров в INI.
- Точечная обработка ввода в штатной очереди сообщений игры, передача остальных сообщений игре.
- Поддержка обоих Rangers.exe и определение FHDRealClockCore для старых русских сохранений.
