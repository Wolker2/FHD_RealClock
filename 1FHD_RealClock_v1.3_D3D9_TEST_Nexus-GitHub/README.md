## Изменения v1.3

- Часы отрисовываются средствами D3D9.
- ЛКМ по часам открывает меню настроек.
- Можно независимо скрывать дату и рамку.
- Прозрачность рамки меняется ползунком от 0 до 100%.
- Цвет времени и даты можно выбирать независимо.
- Параметры сохраняются в `Native/FHDRealClock.ini` рядом с DLL.

По информации исходного архива, тесты эмуляции охватывали два конкретных EXE, но **работа в реальной игре не проверена**. Этот импорт подтверждает лишь контрольные суммы и идентичность исходных файлов. DLL, игровые DAT и другие ресурсы при публикации не изменялись и не пересобирались.

Статус: **TEST**, не RELEASE. Для изменений исходников C/DAT потребуется самостоятельная сборка по [BUILD.md](SOURCE/BUILD.md). Внутри оригинального ZIP содержатся все игровые файлы и готовая DLL.
